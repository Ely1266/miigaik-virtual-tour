# Сравнительный анализ библиотек панорамных экскурсий

Проект: «Виртуальная экскурсия по МИИГАиК». Дата сверки: 24.11.2026.

## 1. Задача и варианты

Веб-приложение знакомит абитуриентов, студентов и гостей МИИГАиК с помещениями и территорией университета при помощи сферических панорам, переходов и информационных меток. Оно рассчитано на браузеры компьютеров и смартфонов; в существующем проекте нужно сохранить подготовленные сцены, тайлы и пользовательский интерфейс без необоснованной миграции.

Варианты: Pannellum 2.5.7 (текущая зависимость), Marzipano 0.10.2 и Photo Sphere Viewer 5.15.1. Версии альтернатив выбраны как конкретные опубликованные выпуски, а не как утверждение об их актуальности. Официальные руководства не привязаны к неизменяемым тегам; описанные функции проверяются по документации, не по установленным альтернативным пакетам.

## 4. Паспорта критериев

Сценарий: сохранить существующий веб-тур с кубическими тайлами нескольких уровней, переходами и информационными точками. Пороговые критерии К1–К4 не компенсируются другими показателями. К5–К6 применяются для выбора библиотеки именно для **существующего** проекта. Ниже зафиксировано правило оценки для исправленной таблицы; это не независимая предварительная регистрация эксперимента.

### К1. Лицензия
- Свойство и назначение: возможность использования и распространения библиотеки в проекте при соблюдении лицензии.
- Шкала: наименований (идентификатор SPDX), единица не применяется, значение целиком.
- Направление: ранжирования лицензий нет. Порог: MIT или Apache-2.0; соблюдение условий обязательно. Вес не применяется.
- Метод: сверить лицензию основной библиотеки с заявлением автора или заголовком лицензии. Источники P1, M1, S1, дата 24.11.2026. Проверка: повторно открыть источник; отдельно проверить сторонние зависимости при распространении.

### К2. Кубические тайлы нескольких разрешений
- Свойство и назначение: наличие документированного способа работы с несколькими уровнями кубических тайлов; необходимо для текущих панорам.
- Шкала наименований: «поддерживается», «не поддерживается», «не установлено»; единица не применяется, фиксируется категория и API.
- Порог: документированная поддержка. Вес не применяется.
- Метод: найти описание кубических тайлов и уровней. Источники P2, M2, S2, дата 24.11.2026. Проверка: повторное чтение соответствующих примеров; фактическую совместимость файлов проверять отдельным прототипом.

### К3. Переходы между сценами
- Свойство и назначение: возможность переключения с одной панорамы на другую по интерактивной метке.
- Шкала наименований: поддерживается / не поддерживается / не установлено; единица не применяется, фиксируется API.
- Порог: существует документированный способ, в том числе с обработчиком или официальным плагином; вес не применяется.
- Метод и проверка: найти пример ссылки на сцену или переключения по событию. Источники P2, M2, S3, дата 24.11.2026. Фактический тест — переход между двумя сценами.

### К4. Информационные метки
- Свойство и назначение: закреплённая за угловой позицией метка с возможностью вывода текста.
- Шкала наименований: поддерживается / не поддерживается / не установлено; единица не применяется.
- Порог: документированная возможность; вес не применяется. Допустим собственный DOM-элемент.
- Метод: найти документацию по меткам и отображению текста. Источники P2, M2, S4, дата 24.11.2026. Проверка: повторно прочитать документацию и в прототипе открыть текст метки.

### К5. Сохранение существующего адаптера движка без изменений
- Свойство: число сохраняемых без изменения файлов из фиксированного набора `src/main.ts`, `src/tourData.ts`. Это показатель архитектурной миграции, а не трудозатрат в часах.
- Шкала абсолютная, единица — файл, точность 1 файл, диапазон 0–2. Чем больше, тем лучше. Вес 0,60: приоритет — сохранение работающей реализации.
- Метод: статически проверить, обращается ли код к API выбранной библиотеки и создаёт ли её собственную конфигурацию. При смене движка не считать файл сохранённым, если в нём требуется адаптация API или формата; обход через новый эмулятор Pannellum в сценарий не входит. Источники R1–R3, P2, M2, S2–S4, дата 24.11.2026.
- Проверка: открыть оба исходных файла и сверить импорт, вызовы и формат конфигурации с API выбранного варианта. Нормирование: n/2.

### К6. Число непосредственно подключаемых пакетов библиотеки в выбранной реализации
- Свойство: число различных пакетов самого движка, которые нужно подключить для К2–К4 по указанным документированным способам. Не включает транзитивные зависимости, сборщик и CSS как отдельный пакет; не является размером сборки или мерой безопасности.
- Шкала абсолютная, единица — пакет, точность 1 пакет. Чем меньше, тем лучше. Вес 0,40: меньше отдельных компонентов интеграции при прочих равных.
- Метод: выписать имена пакетов из примеров и устранить повторы. Источники P2, P3, M2, M3, S2–S5, дата 24.11.2026. Проверка: сверить список импортов; после реализации подтвердить манифестом. Нормирование: 1/n (n ≥ 1).

Итоговая оценка для вариантов, прошедших документарные пороги: 0,60 × К5/2 + 0,40 × 1/К6. Это оценка сохранения текущей реализации и интеграционной комплектности, а не общего качества библиотеки. Порядковых шкал нет; арифметика применяется только к нормированным счётным показателям.

## 8. Вывод

Для продолжения разработки существующей экскурсии МИИГАиК целесообразно сохранить Pannellum 2.5.7. Все три библиотеки документируют поддержку кубических тайлов нескольких разрешений, переходов и информационных меток. Поэтому обязательные функции сами по себе не дают преимущества ни одному варианту. Pannellum позволяет сохранить оба уже имеющихся файла интеграции, тогда как переход на другие движки требует изменения их API и формата конфигурации. Marzipano также позволяет реализовать выбранные функции в одном пакете, а рассмотренная реализация Photo Sphere Viewer подключает четыре пакета самого движка. При заданном приоритете сохранения кода эти данные обосновывают отказ от миграции на текущем этапе. Если появится требование к новым функциям или выяснятся проблемы быстродействия на целевых устройствах, выбор следует пересмотреть по одинаковым измерениям; приведённый анализ не доказывает превосходства Pannellum по скорости или удобству интерфейса.
