## 2. Факты: сканирование npm

В исходном `package.json` одна рабочая зависимость (`pannellum`) и две прямые зависимости разработки (`vite`, `typescript`). Сканирование выполнялось без установки и без изменений lock-файла:

```sh
node -v
npm -v
npm sbom --package-lock-only --sbom-format cyclonedx --offline > /tmp/miigaik-sbom.json
```

Node v22.16.0, npm 10.9.2; код завершения сканера 0. Неизменённый вывод сохранён в [license-scan.txt](license-scan.txt) (JSON CycloneDX 1.5). Это опись **lock-файла**, не перечень содержимого готового JS-бандла. Включены optional-пакеты для разных ОС и архитектур. В 66 строках: MIT — 63, Apache-2.0 — 1, ISC — 1, BSD-3-Clause — 1. Сканер показывает заявленные SPDX; тексты лицензий отдельно проверены у 13 совпадающих по версии пакетов (файлы `node_modules`). У остальных текст конкретного архива не открывался, ссылки на зафиксированные архивы версии приведены для проверки; общая ссылка SPDX не заменяет проверку текста пакета. 

## 3. Запрос и результат лицензионной проверки

Постановка задачи повторного аудита: определить по `package.json`, `package-lock.json`, исходному коду и описи материалов все распространяемые и используемые компоненты. Сопоставить версии и SPDX с выводом `npm sbom`, для каждой позиции установить класс лицензии и условия передачи, сверить тексты доступных лицензий; не считать метаданные доказательством текста лицензии. Отдельно определить неизвестные права на контент, зависимости разработки и условия возможного распространения. Не менять код, зависимости и лицензию проекта; не выдавать непроверенное за установленное.

Результат проверки: повторный запуск `node -v`, `npm -v` и `npm sbom --package-lock-only --sbom-format cyclonedx --offline` подтвердил 66 компонентов и прежний состав SPDX; все пары «имя — версия — лицензия» совпали с сохранённым SBOM. Следующая таблица представляет развёрнутый результат аудита, а журнал содержит проверенные тексты и расхождения. MIT, ISC, BSD-3-Clause и Apache-2.0 относятся к разрешительным лицензиям; для программных ресурсов действуют условия их отдельных текстов. Для версии или материала без подтверждённого источника вывод остаётся «не установлено».

**Мешает распространению:** непроверенные права на сторонние тексты, будущие фотографии и планы — использовать собственные материалы с подтверждёнными правами или получить разрешение; не включать чужие фотографии и планы без основания. Запрещающих коммерческое использование лицензий в метаданных 66 npm-пакетов не выявлено.

**Можно при условиях:** Pannellum и собственный код — сохранить лицензионные уведомления; при поставке инструментов сборки и их зависимостей — выполнить условия MIT/ISC/BSD/Apache-2.0, включая NOTICE при наличии; Leaflet — после подключения соблюдать BSD-2-Clause.

**Не установлено:** точные версии Python-инструментов на рабочей станции автора, происхождение всех сторонних описаний и права на будущие медиа, наличие возможных прав третьих лиц. Отсутствие доказательств запрета не означает разрешение на распространение.

## 7. Вывод о возможности распространения

Распространять и потенциально коммерчески использовать собственный код можно при выполнении условий, но выпуск всего приложения без проверки контента пока не обоснован. Все 66 пакетов npm имеют заявленные разрешительные SPDX, а 13 из них сверены с текстами лицензий. Рабочая библиотека Pannellum 2.5.7 под MIT требует сохранить полный текст и копирайт, поэтому они включены в уведомления. Инструменты разработки не следует передавать вместе с веб-сборкой; если их распространять отдельно, действуют их собственные условия. Перед публикацией необходимо проверить права на тексты, иконки и будущие фотографии, а также подтвердить отсутствие иных правообладателей. При подключении карты, обновлении зависимостей или изменении способа распространения проверку надо повторить. Окончательное решение о выпуске принимает автор после проверки этих ограничений и переноса уведомлений в публикуемую сборку.
