## 2. Выбор лицензий для проекта

* **Для исходного кода веб-приложения:** выбрана лицензия **MIT License** — наиболее гибкая и общепринятая лицензия для веб-разработки с открытым исходным кодом.
* **Для медиаматериалов (сферических панорам, планов этажей и фото):** выбрана лицензия **Creative Commons Attribution 4.0 (CC BY 4.0)** — позволяет МИИГАиК публиковать тур на официальном сайте и использовать его на Днях открытых дверей без роялти, с сохранением указания авторства студента.

## 3. Вывод о возможности распространения

Проект **лицензионно чист**: в коде отсутствуют строгие копилефтные (GPL) зависимости. Приложение может свободно публиковаться на GitHub Pages, демонстрироваться комиссии и встраиваться на официальные порталы МИИГАиК при соблюдении двух условий:
1. Сохранение копирайтов авторов библиотек в заголовочных комментариях JS-файлов;
2. Атрибуция OpenStreetMap на миникарте.
