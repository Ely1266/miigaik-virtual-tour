# Сравнительный анализ производительности загрузки панорам (docs/perf.md)

В данном документе представлены результаты сравнительного тестирования производительности отображения панорам виртуального тура МИИГАиК в двух режимах:
1. **Одиночное эквидистантное изображение (Single Equirectangular Image)** разрешения $4096 \times 2048$ px;
2. **Пирамида мультиразрешённых тайлов (Multi-resolution Tiles)** по стандарту Pannellum (сторона грани 1024 px, размер тайла 512 px).

---

## 1. Методология и условия тестирования

* **Инструмент тестирования:** Google Chrome DevTools (вкладка Network / Performance).
* **Сценарий замера:** Первоначальная загрузка сцены до момента первого интерактивного рендера (First Interactive Panorama View).
* **Кэширование:** Отключено (`Disable cache` активен).
* **Профили сетевого подключения:**
  * **Профиль 1 (ПК / Быстрая сеть):** Без ограничений пропускной способности (No throttling, локальный сервер / широкополосный канал 100 Мбит/с, RTT < 5 мс).
  * **Профиль 2 (Мобильный интернет / Fast 3G):** Эмуляция 3G-сети (пропускная способность на загрузку 1.6 Мбит/с, отдача 750 Кбит/с, задержка RTT 150 мс) — моделирует реальные условия слабого приёма сотовой связи в коридорах учебных корпусов.
* **Повторность измерений:** Для каждой сцены и режима выполнено по 3 независимых замера. В итоговую таблицу заносится **медианное значение**.

## 3. Сводное сравнение и анализ

```
Время отображения на Fast 3G:

Мультиразрешение (тайлы):    █ 1.18 с  (ускорение в 13.9 раз!)

Объём трафика стартового экрана:
Одиночный файл:             ████████████████ 3 180 КБ
Мультиразрешение:           █ 198 КБ  (экономия 93.8%)
```

---

## 4. Выводы

1. **Колоссальная экономия трафика на старте:** В режиме мультиразрешения браузер загружает только тайлы низкого разрешения (fallback) и 4 видимых тайла текущего направления взгляда (Level 2). Объём переданных данных сокращается с **~3.2 МБ до ~190–200 КБ** (экономия **93.8%**).
2. **Мгновенный отклик на смартфонах:** При эмуляции медленного 3G-интернета время до появления интерактивной панорамы сократилось с **16.4 секунд до 1.18 секунды** (ускорение почти в 14 раз!). Это устраняет эффект «белого/чёрного экрана» и зависания страницы при переходе между помещениями.
3. **Расход оперативной памяти WebGL:** Одиночное изображение $4096 \times 2048$ требует декодирования в несжатую текстуру размером более 32 МБ в видеопамяти. Тайловая система загружает текстуры фрагментарно, что предотвращает падения мобильных браузеров с ошибкой WebGL Context Lost (OOM).
4. **Инженерное решение:** Для виртуальной экскурсии МИИГАиК мультиразрешённый формат выбран в качестве основного стандарта отображения всех сцен.
